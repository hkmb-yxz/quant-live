使用说明

📌 如何调整参数？

所有配置都在 GitHub 仓库的 config/ 目录下，直接在网页上编辑并提交即可，几分钟内自动生效：

  • config/options.json：扫描标的、到期范围、形态开关、各形态最低胜率/盈亏比/年化期望、共振权重与最低共振分、邮件预算
  • config/backtest.json：策略开关、参数网格、目标（胜率60%/盈亏比2/夏普2）、样本外比例
  • config/factors.json：因子库与股票池
  • config/app.json：新闻源、关键词与标的映射、波动验证阈值、自动调参开关
  • config/watchlist.json：回测与期权扫描标的

🔁 复盘改善循环

每天 23:00 自动运行：核验昨日热点实际波动是否超过标的平均日波动、结算到期期权计算真实胜率、 对照共振高分命中与普通命中的实际表现、并按实际战绩自动微调各形态胜率门槛（带 ±0.15 边界并记录日志）。

📧 邮件通知

仅五维共振达标（默认 ≥60 分）且方向对齐的新形态命中才会邮件推送；另有每日 22:30 摘要 + 23:00 复盘报告。 邮箱为 QQ 邮箱 SMTP，凭证保存在 GitHub Secrets 中。

🤖 AI 能力

新闻中文摘要与情绪解读、因子 IC 结果解读均由 DeepSeek API 完成（密钥 DEEPSEEK_API_KEY）。 未配置密钥时自动降级为关键词热度规则。
