使用说明

📌 如何调整参数？

所有配置都在 GitHub 仓库的 config/ 目录下，直接在网页上编辑并提交即可，几分钟内自动生效：

  • config/options.json：扫描标的、到期范围、形态开关、最低胜率 / 盈亏比 / 年化期望、邮件预算
  • config/watchlist.json：回测与期权扫描的标的列表
  • config/backtest.json：策略开关与参数（均线、RSI、动量、唐奇安）
  • config/factors.json：因子库与股票池
  • config/app.json：新闻源、AI 调用间隔、关键词权重

📧 邮件通知

新形态命中会立即邮件提醒（每封最多 12 条，每天最多 4 封），另有一封每日 22:30 摘要。 邮箱为 QQ 邮箱 SMTP，凭证保存在 GitHub Secrets 中：QQ_SMTP_SENDER、QQ_SMTP_CODE、EMAIL_RECEIVER。

🤖 AI 能力

新闻中文摘要与情绪解读、因子 IC 结果解读均由 DeepSeek API 完成（密钥 DEEPSEEK_API_KEY）。 未配置密钥时自动降级为关键词热度规则，其他功能不受影响。AI 调用按间隔节流以控制成本。
