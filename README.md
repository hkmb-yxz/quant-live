# 量化实时监控台 (quant-live)

一个**免费、7×24 可持续访问、每日自运行复盘改善**的美股量化实时网页系统，基于 GitHub Actions + GitHub Pages 运行：

- 🔥 **AI 实时金融热点**：聚合 Yahoo Finance / CNBC / MarketWatch / WSJ / Benzinga 的 RSS 热点新闻，关键词热度打分，DeepSeek API 批量中文摘要 + 情绪/影响/板块解读（每 15 分钟）；每日复盘自动核验**实际波动是否超过该标的平均日波动**，标记"世界级热点"
- 📊 **实时回测盈利分析**：均线交叉 / RSI 均值回归 / 动量 / 唐奇安突破对关注列表自动回测，**样本内(历史)/样本外(近端)分段检验 + 过拟合检测**，参数网格按样本外夏普自动优选；目标：**胜率≥60%、盈亏比>2、夏普>2**（可配置），输出达标标记
- 🧬 **实时量化因子挖掘**：16 个因子 × 约 50 只美股，每周横截面 RankIC / ICIR / t 检验，**ICIR 自动加权综合评分榜**，AI 解读最强因子（每小时）
- 🎯 **期权形态抓捕（五维共振）**：扫描美股期权链（CSP / CC / 牛沽价差 / 铁鹰 / 买权），Black-Scholes + 蒙特卡洛估算胜率/盈亏比/年化期望，再叠加**热点消息 + 行情周期 + 技术分析 + 资金投入**共振评分与多空方向，仅共振达标且方向对齐的新命中**邮件推送**（QQ 邮箱）
- 🔁 **每日复盘改善循环**（每天 23:00 北京）：新闻波动验证 → 期权到期实际结算（真实胜率 vs 预估）→ AI 预测准确率 → **按实际战绩自动微调各形态胜率门槛**（±0.15 边界，全程日志）→ 复盘报告邮件
- 📡 网页面板 60 秒自动刷新，数据实时入库

## 网址

部署后访问：`https://<你的GitHub用户名>.github.io/quant-live/`

## 架构

```
GitHub Actions 定时任务（免费）
 ├─ 每 15 分钟：热点新闻 + AI 解读
 ├─ 每小时 5/35 分：期权扫描 + 共振过滤邮件提醒
 ├─ 每小时 20 分：回测 + 因子挖掘 + AI 解读
 ├─ 每天 22:30(北京)：每日摘要邮件
 └─ 每天 23:00(北京)：复盘改善循环（波动验证/到期结算/自动调参）+ 复盘邮件
        ↓ 数据写入仓库 data/*.json
GitHub Pages（免费静态托管）
 └─ 仪表盘自动读取数据并 60 秒刷新
```

## 配置（改完提交即生效，无需改代码）

| 文件 | 内容 |
| --- | --- |
| `config/options.json` | 扫描标的、到期/行权范围、形态开关、**各形态最低胜率/盈亏比/年化期望**、**共振权重与最低共振分**、邮件预算 |
| `config/backtest.json` | 策略开关、参数网格、**回测目标（胜率60%/盈亏比2/夏普2）**、样本外比例 |
| `config/factors.json` | 因子库与股票池 |
| `config/app.json` | 新闻源、关键词与**标的映射**、波动验证阈值、AI 调用间隔、自动调参开关 |
| `config/watchlist.json` | 回测与期权扫描标的 |

## Secrets（GitHub 仓库 Settings → Secrets and variables → Actions）

| 名称 | 必填 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 否 | DeepSeek API 密钥；不配置则新闻/因子降级为规则模式 |
| `QQ_SMTP_SENDER` | 邮件必填 | QQ 邮箱地址，如 `12345@qq.com` |
| `QQ_SMTP_CODE` | 邮件必填 | QQ 邮箱 SMTP 授权码（邮箱设置→账户→开启 SMTP 生成） |
| `EMAIL_RECEIVER` | 否 | 收件地址，默认同发件人 |

## 本地运行

```bash
pip install -r requirements.txt
python -m app.main --mode all            # 全量跑一遍（不发邮件、不用 AI 除非配置密钥）
python -m app.main --mode all --force-ai --allow-email
```
